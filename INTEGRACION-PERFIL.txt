# INTEGRACIÓN DEL PERFIL TOPOGRÁFICO EN MapComponentGL.jsx
#
# Este archivo documenta los tres cambios exactos que hay que hacer en
# app/MapComponentGL.jsx para activar el perfil topográfico.
#
# Los archivos app/hooks/map/useTerrainProfileGL.js y
# app/components/TerrainProfile.jsx ya están creados y funcionales.

## CAMBIO 1: Importaciones (al inicio del archivo, junto a las demás)

Después de la línea:
    import { useTerrainRasterGL } from "./hooks/map/useTerrainRasterGL"

Añadir:
    import { useTerrainProfileGL } from "./hooks/map/useTerrainProfileGL"

Después de la línea:
    import { TerrainQuery } from "./components/TerrainQuery"

Añadir:
    import { TerrainProfile } from "./components/TerrainProfile"

Dentro del import de lucide-react, añadir "Activity" a la lista:
    import {
      Activity,
      Box,
      ...

## CAMBIO 2: Estado y hook (dentro de MapComponentGL, después de terrainResult)

Después de la línea:
    const [terrainResult, setTerrainResult] = useState(null)

Añadir:
    const [showTerrainProfile, setShowTerrainProfile] = useState(false)

Y después de la línea donde se llama useTerrainGL (buscar "useTerrainGL("),
añadir:
    const { profile: terrainProfileData, unavailable: terrainProfileUnavailable, computeProfile, clearProfile } = useTerrainProfileGL(mapRef, { setTerrainForQuery: setTerrainForQuery })

NOTA: setTerrainForQuery viene del destructuring de useTerrainGL.
Si no está en el destructuring, añadirlo ahí también.

## CAMBIO 3: Render del panel (dentro del JSX, donde están los demás paneles)

Buscar donde se renderiza <TerrainQuery ... /> y añadir justo después:

    {showTerrainProfile && (
      <div className="absolute bottom-4 left-4 z-30 w-[min(24rem,calc(100vw-2rem))]">
        <TerrainProfile
          profile={terrainProfileData}
          unavailable={terrainProfileUnavailable}
          onClose={() => {
            setShowTerrainProfile(false)
            clearProfile()
          }}
        />
      </div>
    )}

## CAMBIO 4 (opcional): Botón para activar el perfil

En el menú del mapa (dentro del MapMenuPanel del terreno), añadir un MapMenuItem:

    <MapMenuItem
      icon={Activity}
      name="Perfil topográfico"
      hint="Dibuja una línea y ve su elevación"
      active={showTerrainProfile}
      onClick={() => {
        if (showTerrainProfile) {
          setShowTerrainProfile(false)
          clearProfile()
        } else {
          setShowTerrainProfile(true)
        }
      }}
    />

## CÓMO SE USA

1. El usuario abre el menú del terreno y pulsa "Perfil topográfico".
2. Aparece el panel vacío en la esquina inferior izquierda.
3. El usuario dibuja una línea con la herramienta de dibujo existente.
4. Al terminar la línea, el perfil se calcula y se muestra en el panel.
5. Al pasar el cursor sobre el gráfico, se ve la cota en cada punto.
6. La X cierra el perfil y limpia el estado.
